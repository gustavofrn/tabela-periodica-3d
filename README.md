# Tabela Periódica 3D

Visualização interativa da tabela periódica com 118 elementos e animações tridimensionais, desenvolvida em HTML, CSS e JavaScript utilizando Three.js.

## Funcionalidades

- Visualização em quatro formatos: **table**, **sphere**, **helix** e **grid**.
- Transições animadas entre os formatos.
- Navegação interativa em 3D com controles de câmera.
- Cartões com número atômico, símbolo e nome do elemento.
- Layout adaptado para diferentes tamanhos de tela.

## Tecnologias

- HTML5
- CSS3
- JavaScript
- Three.js (CSS3DRenderer e TrackballControls)
- Tween.js

## Como executar

1. Baixe ou clone este repositório.
2. Abra `index.html` em um navegador moderno com acesso à internet.
3. Utilize os botões na parte superior para alternar as visualizações.

As bibliotecas são carregadas por CDN; é necessária uma conexão com a internet.
